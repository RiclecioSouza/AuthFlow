# AuthFlow
O projeto possui validação de formulário, armazenamento de dados no localStorage e exibição de uma mensagem de boas-vindas através de um modal.

## 🚀 Funcionalidades
- 👤 Cadastro de usuário
- ✅ Validação do campo de usuário
- 🔒 Validação da senha
- 🔢 Senha com mínimo de 6 caracteres
- 💾 Armazenamento do nome utilizando localStorage
- 📥 Recuperação dos dados armazenados
- 👋 Modal de boas-vindas
- 🧹 Limpeza dos campos após o cadastro
- 🗑️ Remoção dos dados do localStorage ao fechar o modal
- 📱 Interface simples e responsiva

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- LocalStorage
